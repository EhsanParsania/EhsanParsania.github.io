Project

NexusHome

IoT Smart Home Hub with Cloud-Driven Automation

Dec 2025 – Present

Overview

NexusHome is an IoT smart home hub that connects embedded devices to cloud infrastructure, enabling automation, voice control, and predictive behavior based on sensor data and usage patterns.

Technologies

  • Raspberry Pi
  • ESP32
  • Python
  • FastAPI
  • MQTT
  • React
  • Cloud infrastructure
  • Voice automation
  • Predictive automation

Architecture

Embedded devices (ESP32) communicate via MQTT to a Raspberry Pi hub running Python/FastAPI. The React frontend provides monitoring and control. Cloud infrastructure handles remote access, data processing, and automation rules.
